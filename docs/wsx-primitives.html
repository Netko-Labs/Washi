WSX primitives

The page format Washi writes and renders, and the closed registry it may use: 57 primitives in seven groups, their props from the zod specs, what each looks like, and the four small languages a page speaks — state, expr, bind and action.

generated against @washi/paper · 2026-10-2157 primitives · 7 groupsreplaces docs/wsx.mdregistry is the truth: packages/shared/paper/src/registry/specs.ts

30-second version

  1. JSX as data. A page is one JSX element tree stored as text. It is parsed, validated and rendered; nothing in it executes.
  2. One root Sheet. <Sheet title wsx="1"> is the page. No fragments, no second root.
  3. Registry only. Capitalised names from the 56 below. No <div>, no custom components; an unknown name is written as <Missing kind reason />.
  4. Props are JSON literals. Strings, numbers, booleans, null, arrays, objects. Anything executable is refused at parse.
  5. Four enums. variant tone size emphasis are the whole visual API. No hex, no px, no font. Plus span and a layout-only class.
  6. state · expr · bind · action are a page's whole behaviour. Controls write state keys; expr computes from them and from tables; bind reads a table live; action names a hanko verb. There are no handlers.
01

What a page is

A page looks like React and is not React. It is data: an element tree with literal props, checked against a closed registry before it is saved and again before it is drawn. The grammar is small enough to list in full.

The grammar

Every rule below is enforced by parse (@washi/wsx) or by validate against paperRegistry. Breaking one is an error, not a warning — except the complexity budget (§10).

Serialization

serialize(tree) is the canonical text, and parse(serialize(tree)) round-trips. The parser collapses runs of whitespace in JSX text to one space and trims each run, so typed text with real spacing has to go in as a string literal — the serializer decides that per text node.

InputWritten as
a true propthe bare attribute: <Item done>
a string propkey="…", JSON-escaped (so an inner " survives)
any other propkey={json} — numbers, booleans, null, arrays, objects
plain textbare, when it has no leading/trailing whitespace, no newline, no double space and none of < > { } &
any other text{"…"} — a JSON string literal child, so a < b, two spaces, or a newline all come back byte-for-byte
one text childinline: <Text>hello</Text>
several childrenone per line, two-space indent, closing tag on its own line; the file ends with a newline
no childrenself-closing <Divider /> regardless of policy
The parser also reads {123} and {true} children as text, skips empty {} expressions, and refuses {[…]} / {{…}} children: object and array literals are not allowed as children.

04

State

A page declares its state on the Sheet. Controls write keys; expr reads them. Values are scalars. Nothing else in a page remembers anything.

<Sheet title="Kit" state={{ local: { tab: 'Board', open: null }, stored: { mine: false, budget: 40 } }}>
  <Switch state="mine" label="Only mine" />
  <Slider state="budget" min={0} max={100} step={5} label="Budget" />
  <Show expr="mine = true and budget > 20">…</Show>
  <Tabs labels={['Board', 'List']} state="tab">…</Tabs>
  <Drawer state="open" bind={{ table: 'issues' }} title="$row.name">…</Drawer>
</Sheet>

The scalar rule. A state value is string | number | boolean | null — the same scalarSchema as a table cell. No arrays, no objects: a key that needs a list is a table.

05

Expressions

A closed grammar, tokenized and parsed to an AST by @washi/wsx, evaluated by the renderer with a depth cap of 24 and a step budget of 2000, from source of at most 512 characters. It computes a value. It cannot define, loop, or format.

In

  • numbers (3, 0.5), strings in ' or " with \n \t escapes, true false null
  • arithmetic + - * /, unary -
  • comparison = != < <= > >= (== reads as =)
  • and or not, parentheses
  • a state key by bare name
  • $row.column inside Repeat or a bound Drawer
  • aggregates count sum avg min max over a table, with an optional where
  • now(), days(a, b), month(d), year(d) and when(cond, a, b)

Out — and the message

  • % — not in the grammar; ? : — ternaries are not allowed
  • [ ] { } — array literals and indexing / object literals are not allowed
  • ` template strings, & | ^ ~ bitwise (use and / or), ; statements, ! (use not), => lambdas
  • reserved words function new if else for while do return let const var class this import export typeof in of yield async await — expr has no definitions, loops, or assignment
  • unknown calls — only count, sum, avg, min, max, now, days; method calls; property chains longer than one segment; . on anything but $row or a table inside an aggregate
  • nested aggregates, and where outside an aggregate
  • joining a number into a string: 'Total: ' + n → `+` cannot join string and number: expr may compute a value, never format it — use Money/Text

Aggregates

Form: fn(source) or fn(source.column), optionally where … before the closing paren. source is a table name. count takes no column; the others need one. Inside where a bare name is the row's column first, then a state key (a clash is reported as a shadowing warning). Rows whose where is not exactly true are skipped; non-numeric cells are skipped by sum avg min max.

fnResultOf no rows
count(t)rows kept by where0
sum(t.c)sum of numeric cells0
avg(t.c)mean of numeric cellsnull
min(t.c) max(t.c)extreme numeric cellnull
$scope is reserved as an aggregate source (count($scope), the rows of the enclosing Repeat) but the renderer passes no scope rows today, so it evaluates to `$scope` has no rows in this context. later

Semantics

  • + adds two numbers or joins two strings; - * / need numbers. Either side null → null.
  • Division by zero is null, never an error or Infinity.
  • = and != are strict. Ordering compares two numbers or two strings; mixed types compare false.
  • and / or short-circuit and want booleans: null reads as false; a number or string there is an error.
  • now() is milliseconds, frozen per render pass — two reads in one page agree. days(a, b) is trunc((b − a) / 86 400 000); each side an ISO date string or a number of ms; null in → null out.
  • month(d) is 'YYYY-MM' and year(d) a number, both in UTC from an ISO date or ms; null in → null out. when(cond, a, b) evaluates only the branch taken, so when(qty = 0, 0, total / qty) never divides by zero (if stays reserved: there is no control flow). The same grammar defines a table's formula columns (D73), where a bare name is the row's own column.
  • Tables an expression aggregates over are prefetched once per sheet (limit: 1000) and again after every verb or remote change, so evaluation is synchronous.
  • At render a bad expression — syntax, unknown name, type error, budget — renders as null; useExprValue never throws. Stat shows —, Show hides, Progress shows 0 %.

06

Live data: bind

A bind is an ink query descriptor against a table in the workspace file — the same shape everywhere. The host runs it; the primitive draws the rows; every verb and every remote change makes it run again.

bind={{
  table: 'issues',
  where: [{ column: 'status', op: 'ne', value: 'Done' }, { column: 'labels', op: 'contains', value: 'bug' }],
  orderBy: { column: 'points', direction: 'desc' },
  limit: 50,
}}
FieldShapeNotes
tablerequiredstringA table name: snake_case identifier when defined.
where≤16 × { column, op, value }ANDed. op: eq ne gt gte lt lte contains in. value a scalar, a list (≤100) for in, or { state: 'key' } — the page reads that state key before the query leaves, and an unset, empty or null key drops the filter (D72), so one set of views follows a Select.
params≤ named valuesWhat the table's rollups' { param } filters read (D74) — a scalar, or { state: 'key' } resolved like a filter; unset is left out, and its filter drops. id is always filterable. A comparison against null is never true (SQL); contains is a case-insensitive substring. On a list column (multi_select, relation) eq contains in mean holds any of and ne holds none of.
orderBy{ column, direction }asc (default) or desc.
limitinteger 1–1000
groupBy{ column, aggregates: [{ fn, column? }] }1–8 aggregates, fn count sum avg min max. Returns one row per group — feeds a Chart directly (label = the group column, value = the first numeric column).

Every column named must exist on the table (unknownQueryColumns). Cells arrive typed as the column; a list cell reads on the page as its items, comma-joined (toRows), so $row.labels is a string.

Over time — history

Chart history={{ table, where?, range }} answers how many rows matched where when each day closed (UTC), for range 7d 14d 30d 90d (default 30d). Every row write appends what the row became to record_changes; history replays that log day by day with matchesFilters — the executor's own filter semantics, in memory. A burn-up is where on the done status; a backlog is ne. The host returns { day, count } rows; the chart labels them Oct 1.

Refetch rules

  1. Once per sheet. On mount, every bind runs (useBind), and every table an expr aggregates over is fetched whole (useDataTables).
  2. After every verb. useRunAction bumps the data version after the host's runAction resolves; Field, Board, Roadmap and Database do the same after their own writes. Every bind and prefetch re-runs.
  3. On workspaceChanged. The host's onDataChange (the studio's live.onChange subscription) bumps the same version, so a teammate's or Washi's write redraws the page.

Bound and cell()

Empty, loading and error ship with every bound primitive, designed once in Bound: Loading… (pulsing), This block could not load — reason (danger), and the empty sentence — Nothing here yet. unless the page sets empty="…". That sentence is the only override. cell(value) is how any primitive prints a cell: null → nothing, booleans → ✓ / —, everything else String().

08

The registry

Fifty-four primitives in seven groups — PRIMITIVE_GROUPS: frame 6 · text 14 · surface 4 · data out 14 · data in 8 · flow 5 · kit 3. Each block below is read off its zod spec: props, children policy, placement. Every primitive takes the four enums, span and class (§3) unless it says otherwise; the tables list only its own props.

Children: none self-closing · text text only · nodes elements and text. A sketch shows the primitive as paper draws it — static HTML, not the renderer.

09

Missing and requests

There is no escape hatch. A design that needs something not in the registry writes <Missing kind reason />: the page stays valid, the reader sees a labelled gap, and the registry hears about it.

  1. The validator says so. An unknown name fails with <Matrix> is not a registry primitive — write <Missing kind="Matrix" reason="…" /> and the registry hears about it. Washi's sheet_check returns the same.
  2. The gate collects them. checkSource returns { ok, diagnostics, missing }; missing is extractMissing(root) — { kind, reason, path } per element, path like Sheet > Section > Missing. That list is the registry request.
  3. At render the Missing component draws Kind is not in the registry yet — reason in a dashed, hatched box. The renderer also falls back to it for any element name it has no component for, so a page never goes blank.

Known gaps, to be written as Missing until they land: Matrix · Calendar · Timer · Scene / Beat / Stepper · Filter / Facet / Search / Sort / Segment. later

Validation

Two gates, one check. checkSource — parse, then validate against paperRegistry — runs in the service before any persist and in the client before render. Errors name the element path, the prop and the legal alternative.

The gates

WhereWhatOn failure
createSheetFromSource / updateSheetFromSource (service)checkSource(write.source); warnings never blockthrows SheetValidationError with diagnostics → 400

Parse stops at the first problem and throws WsxParseError (one diagnostic, with the location when Babel can attribute it). Validation walks the whole tree and reports everything.

Budgets

paperRegistry.budget = 400 nodes · 8 binds · 24 expressions per sheet, counted on elements with a bind / expr prop. Over any of them is one warning on Sheet — a prompt to split into linked sheets via Ref, never an error, and never a blocked save.

Source mode in the studio

The </> toggle while editing (or Edit source in the page menu) opens the raw WSX in CodeMirror. It runs the server's own check client-side on every keystroke — parse, then validate against paperRegistry — lists the problems under the editor, autosaves only a valid draft through sheets.update with baseVersion, and holds Done while the draft has errors (Not saved — the source has errors).

How a page is edited

Four hands write the same text: a person typing blocks, a person in source mode, Washi through sheet_replace, and a canvas rewriting itself. All of them go through sheets.update and the same gate; the Loro doc merges them.

Typed blocks

The page editor (apps/studio/src/components/page-editor) edits the sheet's top level as blocks. A top-level element becomes a typed block when it is plain text — one text run, or one plain Text inside:

Everything else — any other primitive, text with inline marks, a List with a non-plain Item — is a locked block, kept byte-for-byte and rendered by paper in place. A block's own props (a tone, a size) survive the round-trip. Typing pauses 700ms, then the sheet is rebuilt (toSheet) and saved through sheets.update with baseVersion — the same validation as Washi's. Empty text blocks are dropped. The first block, when it is a level-1 heading, names the page.

/ live blocks

Besides the text kinds, the slash menu drops live blocks in as locked blocks: New database (/database Bugs defines table bugs with name text and a three-step status, then inserts <Database table="bugs" />), Linked view of any existing table (<Database table="…" />), and Progress for any table with a done group — <Chart kind="area" history={{ table, where: [{ column: status, op: 'in', value: doneValues }], range: '30d' }} />.

Washi's writes

sheet_create and sheet_replace are CHANGE_TOOLS: they land without asking, marked edited_by = 'washi', and each pushes the page's prior state onto sheet_revisions — the undo stack, cleared the moment a person changes the page so Undo never erases their words (undoWashiWrite; SheetUndoError when there is nothing of Washi's left). sheet_replace sends the version it read as baseVersion, so a person typing meanwhile merges rather than loses. Washi shows on the page for 20s after each rewrite.

Canvas self-edits

A hand edit on a Canvas calls PaperHost.replaceNode(from, to). In view mode SheetView's host swaps the element in the tree and saves through sheets.update; in the page editor LockedBlock routes the swap into the editor store instead (swapNode, keeping untouched elements' identity), so autosave never writes a stale canvas over a fresh one.
