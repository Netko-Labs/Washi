how to read

Start with the PRD, judge with the canvas

The PRD says what must be true. The canvas shows what that looks like. When they disagree, the PRD wins and the canvas gets fixed.

  • Each doc opens with a 30-second version and every section leads with the point. Skim those first.
  • decided open later mark the state of every call; have new cut mark scope.
  • The canvas pans with the wheel, zooms with ⌘ + wheel, fits with 0. Click a frame to zoom to it; the link in the address bar then opens that frame.
