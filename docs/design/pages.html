Two kinds of wrong. 1 the header holds: Not saved — the source has errors, ‹/› and Done disabled. 2 a parse error knows its line, so it marks the gutter and underlines; a schema error (an element the registry does not have, a prop it does not take) carries a path instead, so 3 the problems list shows line:col for the first and Sheet > Hero for the second, and the gutter stays quiet for it. Fix both and the next pause saves. The parser's own sentence is shown as the parser says it; the registry message is the validator's template.
Decisions
  1. Only the top level becomes blocks, and only plain-text kinds: a nested or marked-up element is locked rather than lossy. Typing can never silently flatten what Washi designed.
  2. Autosave sends baseVersion so a person and Washi can write the same page in the same minute and the server merges on a fork; the editor only absorbs a remote change while it has nothing unsaved.
  3. Source mode has no hooks tab, no preview pane: the WSX is the page, and the checker is the server's — so what saves here is exactly what Washi is held to.

How we shipRename

How we work

Issues, projects, and the Friday review.

1 2
1 Rename is an inline form in the menu's popover: one field (Page name, 200 chars), one button. 2 it writes the title only — the sheet's first <Title> is left alone, so the heading on the page can differ from the name in the tree, as in Notion. A page whose title comes from its first typed h1 keeps following it until renamed here.
Decisions
  1. Icon, cover, width and name are rows in sheets, not WSX: a cover change by one person must not conflict with a paragraph typed by another, and Washi must never have to parse a cover to rewrite a list.
  2. Presets over uploads: no blob store, no CDN, the same nine on every host — and a page cannot be made ugly in a way the kit did not foresee.
  3. Move to… is flat search because the tree is already in the sidebar (drag works there); the panel is for when you know the name.
