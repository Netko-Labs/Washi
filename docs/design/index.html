Netko Labs · Washi · design

Every screen, on one canvas。

Seven pages of frames, one per area. Each frame is the studio or the desktop as the code has it today; a frame whose name ends in · proposed is a change, and its note says why.

The PRD links into these frames. When a frame and the PRD disagree, the PRD wins and the frame gets fixed.

  1. shell — sidebar, tabs, header, dashboard, find, inbox, trash
  2. pages — reading, typing, source mode, chrome, together
  3. data — databases, rows as pages, charts, roadmap, canvas, the team space
  4. work — the golden flow: investigation → tickets → PR → the loop
  5. agent — the mascot door, the panel, the desk, routines
  6. account — sign in, workspaces, people, host
  7. desktop — onboarding, daily note, settings, offline
