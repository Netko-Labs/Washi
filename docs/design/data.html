Stat and Progress: the serif figure with an uppercase label and a hint; the bar with its label and percent. Both take value or expr (the closed expr grammar over page state — not a query; Washi writes the number in). 1 trend is one of up · down · flat and only colours the glyph. 2 no value prints an em dash. 3 Progress clamps to 0–1 and rounds. Why history is append-only
  1. Every write to a row appends what it became. No diffs, no "updated_at" guessing: a day is the last state of each row before midnight.
  2. Charts replay it, so a chart can never disagree with the table — same rows, same filters, one clock (UTC day-end).
  3. The log is also the table Undo that's still open in todo: replaying to a point is the same walk.
