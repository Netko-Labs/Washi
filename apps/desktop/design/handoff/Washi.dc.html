# design principles
01  every action reachable in ≤ 2 keystrokes

03  latency is the only aesthetic that matters

Command surface

The palette is the app. Everything — panes, sessions, SSH targets, theme — resolves through a single fuzzy input bound to ctrl-space. Menus exist only as a discoverability fallback and are never the fastest path.

Written by {{ agentName }} · from 6 sources in Research

Benchmarks across four competing clients put p99 keystroke-to-glyph latency between 8ms and 41ms. Anything above ~16ms is perceptible during fast repeat input, so the render budget for a frame should be treated as a hard ceiling, not a target.

Scrollback should be basically infinite so users never lose anything.
Scrollback is capped at 200k lines per pane and spills to a memory-mapped file on disk, so history survives restarts without holding the buffer in RAM.

A recipe app that smells like a kitchen

Hearth

Slow software. The app should feel like a well-worn cookbook — warm paper, soft corners, nothing blinking for attention.

Jo Lindqvist · edited yesterday Agent drafting
Palette

Nothing is pure white and nothing is pure black. Cards sit on cream at 18px radius with a 1px oat-colored hairline — no drop shadows, because paper doesn't float.

Cooking mode

One step at a time, type at 22px minimum, screen stays awake, and a thumb-sized "next" target in the bottom third of the screen. Timers are inline with the step that needs them — never a separate tab.

Drafted by {{ agentName }} · 2 min ago · not yet reviewed

Accessibility note: the cream-on-brown pairing above measures 4.7:1, which clears AA for body text but fails AA-large for the 13px uppercase labels. Suggest darkening the label color to #8a5f38 — I can apply this everywhere it appears.

No radius. No shadow. No gradient. Structure carries all the meaning: hairlines become 2–3px rules, and hierarchy is made with size and weight only.

Listing grid

Four columns on desktop, two on tablet, one on phone. Images are square, cropped hard, never rounded. Price sits in 800 weight at the same size as the title — the buyer's eye should land on both at once.
